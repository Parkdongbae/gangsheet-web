1. 무엇을·왜: `PRD.md` → 2. 어떻게 보이나: `02` → 3. 정확한 규칙: `01`, `03` → 4. 사용자 경험: `04` → 5. 무엇을 넣고 무엇을 검증했나: `05`.

## 표기 규칙

- 표기가 없으면 v0.5.0 코드에서 확인한 사실이다. 이전 판의 "(v0.5.0 신규)"는 구현이 끝나 모두 사실로 바뀌었다.
- **실측**: 2026-11-23, 개발 PC, Chromium 계열 브라우저, 테스트 이미지 1104×1428 JPG 인물 사진 1장으로 측정한 값. 표본이 1장이라 일반화하지 않는다.
- **미검증**: 측정·시험하지 않았다는 뜻이다. 추정으로 채우지 않는다.
- **향후**: 구현하지 않았고 이번 릴리스 범위 밖인 항목. 코드에 없다.
